1. Write order vs run order

SELECT   cols / expressions AS alias      -- 5th
FROM     table t JOIN other o ON t.id = o.id  -- 1st
WHERE    row filter (no COUNT/SUM here)  -- 2nd
GROUP BY non-aggregated columns          -- 3rd
HAVING   group filter (COUNT/SUM allowed) -- 4th
ORDER BY col DESC, col2 ASC              -- 6th
LIMIT    n;                              -- 7th

6. Traps (each one costs points)

  1. Exact text. 'Mr.' ≠ 'Mr. '. The grader compares strings character by character. Copy the spaces and punctuation from the example.
  2. NOT NULL + CHECK on a table with rows. ADD CustomerPhone VARCHAR(50) NOT NULL fills old rows with ''; then CHECK (… REGEXP '^[0-9]+$') fails with error 4025 (tested on this MariaDB). Add the column nullable, then the constraint.
  3. Aggregate in WHERE. WHERE COUNT(*) > 10 is an error. Use HAVING.
  4. GROUP BY. Every SELECT column that is not inside COUNT/SUM/… must be in GROUP BY.
  5. LEFT JOIN + COUNT(*). An employee with 0 transactions gets 1. Use COUNT(th.TransactionID).
  6. LIMIT 1 for "the most". Ties disappear. Use HAVING COUNT(*) = (SELECT MAX(...) FROM (...) AS x).
  7. Derived tables need an alias: FROM (SELECT …) AS x.
  8. LIKE without % means an exact match. LIKE '%Cheese' = ends with; 'Cheese%' = starts with.
  9. Last word / first word. Last: RIGHT(s, POSITION(' ' IN REVERSE(s)) - 1). First: LEFT(s, POSITION(' ' IN s) - 1). Forgetting - 1 keeps the space.
  10. Replace after '@': INSERT(email, POSITION('@' IN email) + 1, LENGTH(email), 'gmail.com'). Add before '@': INSERT(email, LOCATE('@', email), 0, 'lady').
  11. Even/odd ID: CAST(RIGHT(TransactionID, 3) AS UNSIGNED) % 2 = 0.
  12. Alias with a space needs backticks: AS `Transaction Count`. Strings use single quotes. An alias cannot be used in WHERE (it can in ORDER BY and HAVING).
  13. NULL: write IS NULL / IS NOT NULL, never = NULL.
  14. ON DELETE CASCADE: deleting TR001 from TransactionHeader also deletes its TransactionDetail rows.
  15. UNION removes duplicate rows; UNION ALL keeps them. Both parts need the same number of columns in the same order.
  16. DISTINCT works on the whole row, not one column. "Duplicates counted once" inside a count = COUNT(DISTINCT …).
  17. INTERVAL uses singular units: INTERVAL 1 YEAR, INTERVAL 7 DAY.
  18. DROP INDEX needs ON table. DROP VIEW IF EXISTS a, b drops two at once.
  19. GROUP_CONCAT separates with , (no space) unless you write SEPARATOR ', '.
  20. Table name case: Mac and Windows ignore it, Linux does not. Write the exact case from the question.
  21. Run order in a script: create parents (MsCategory, MsCustomer, MsEmployee) before children (MsProduct, TransactionHeader, TransactionDetail); drop children first.
